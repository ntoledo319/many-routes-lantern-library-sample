# The Lantern Library — free mini hunt

An original two-clue indoor paper hunt. Adult setup and optional reading help. Download Letter or A4, print two pages, and use common objects or labeled tabletop stations.

These free sample PDFs may be shared unchanged for free with attribution; see LICENSE.txt. They do not contain the full eight-clue kit. No purchases, forms, analytics or email signup. No physical-print or child playtest claim is made.
